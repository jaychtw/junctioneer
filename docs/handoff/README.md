# Junctioneer — Codex handoff package

This package is ready to hand to Codex for **full v1.0 implementation** (not just a prototype).

Read in this order:
1. `CODEX-HANDOFF.md` — blocking private-UGDS preflight and implementation assignment.
2. `GDD.md` — complete approved game direction and acceptance criteria.
3. `LEVEL-AUTHORING.md` — exact puzzle authoring/solver contract.
4. `QA-CHECKLIST.md` — evidence and quality gates.

**UGDS is not bundled**: it remains private and must be fetched and verified at `v1.0.0`, commit `d5c6696efdd6efc028118600466db44aecae0c9b`. No verified UGDS means no implementation.

The project repository has not been created or confirmed. The user may supply these files to Codex in a new `junctioneer` repo or workspace. The creative director must approve the representative in-engine visual POC before full art production. This is a gate **within** the full-build assignment.
